## 🚀 Getting Started

### Clone the repository
```bash
git clone https://github.com/michaelyurachek/michaelyurachek.github.io.git
```

### Open the project
```bash
cd michaelyurachek.github.io
```

### Launch in browser
Simply open ``index.html`` in your preferred web browser.

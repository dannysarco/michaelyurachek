# 🛠️ Setup Instructions

Welcome! If you'd like to run, modify, or explore this portfolio locally, follow the steps below.

---

## 🔧 Prerequisites

* A modern web browser (Chrome, Firefox, Edge, Safari)
* Basic understanding of HTML, CSS, and JavaScript
* (Optional) A code editor like Visual Studio Code (VS Code)

---

## ⚙️ Running the Project Locally

### 1. Clone the repository

Download the project to your machine using Git:

```bash
git clone https://github.com/michaelyurachek/michaelyurachek.github.io.git
```
---
### 2. Navigate to the project folder
Move into the downloaded project directory:
```bash
cd michaelyurachek.github.io
```
---
### 3. Open the project
You can launch the site in two ways:
1. Direct Method:
    * Double-click index.html to open it in your default browser.
2. Recommended Development Method:
    * Open the project folder in VS Code (or your preferred editor).
    * Use the Live Server extension (in VS Code) to serve the site locally with live reloading.
---
